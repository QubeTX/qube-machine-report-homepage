QubeTX has three tools for checking your computer and its internet connection. Choose one based on what you need to find out.

## Choose a tool

| Your task | Tool guide | Installation |
| --- | --- | --- |
| Check computer specifications or save a system report | [TR-300 and `report`](/tr300) | [Install TR-300](/tr300/installation) |
| Investigate connection problems or test internet speed | [ND-300 and SpeedQX](/nd300) | [Install ND-300](/nd300/installation) |
| Watch system activity in a terminal or desktop app | [SD-300](/sd300) | [Install SD-300](/sd300/installation) |

Each guide starts with what the tool does, then covers installation, commands, basic use cases, and advanced use cases. Installation pages also explain offline setup, updates, and removal.

## Common tasks

- [Save a machine report to share with support](/tr300/examples#save-a-report-for-support).
- [Check a connection without running a speed test](/nd300/examples#check-your-connection).
- [Test download and upload speed](/nd300/speedqx).
- [Find which apps use the most memory](/sd300/examples#find-apps-using-the-most-memory).
- [Open and use the SD-300 desktop app](/sd300/desktop).

For installation errors or missing readings, see [Troubleshooting](/troubleshooting).

These guides describe TR-300 4.4.0, ND-300 4.0.1, and SD-300 4.1.0. See [Source versions](/sources) for the releases used to check them.
