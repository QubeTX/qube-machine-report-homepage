title: "ND-300 network diagnostics"
description: "Inspect connectivity and choose a focused diagnostic workflow."
---

`nd300` provides a summary of the active connection. `nd300 --tech` adds deeper diagnostics. The same package installs `speedqx` for a standalone throughput test.

Start with `nd300 --fast` when you want connectivity diagnostics without the speed test. It still performs network probes; fast does not mean offline. Recovery and DNS changes are separate, explicit actions.
