---
title: "SD-300 system monitoring"
description: "Monitor the computer in a terminal or a native desktop app."
---

SD-300 provides a terminal monitor and a native desktop app. Managed installations deliver both as one product; each can be used independently.

```sh
sd300
sd300 gui
```

The first command opens the terminal mode chooser. The second opens or focuses the installed desktop app. It does not replace the terminal interface.

Missing sensors and denied permissions remain explicit. An unavailable measurement is not a healthy reading or a zero.
